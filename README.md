# Normal-Mode-Decomposition-of-the-Internal-Wave
Code for Normal Mode Decomposition of the Non-Phase-Locked1 Internal Tide and the Internal Wave Continuum
Archived LV1 IMOS data used in this study are available at:
 [TS_source_files](https://zenodo.org/records/20695706).

To reproduce the results, please follow the workflow below:

Run Temp obs to displacement.ipynb first to convert LV1 temperature data into LV3 internal wave displacement data.
Run IW amplitude model fit.ipynb to estimate the model parameters.
Run IW amplitude result analysis.ipynb to generate all result figures and plots.
